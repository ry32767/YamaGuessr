使い方
1. リポジトリのルートで python -m http.server を実行し、 /pipeline/review.html を開く
2. pipeline/data/ の candidates.json などを自動で読み込む
3. ピンをクリック → A で採用 / R で却下
4. 採用したら ← → で切り出し時刻を0.5秒ずつ調整
5. 地図の空白を Shift+クリック で地点を手動追加
6. 「書き出し」で confirmed_points.json を保存

読み込めない場合は「ファイルを読み込む」から candidates.json / track.json / previews/index.json を選んでください。
