# 効果音の出典

このプロジェクトの効果音は**音源ファイルを一切使っていない**。すべて実行時に
Web Audio API のオシレータで合成している（実装は [src/sound.ts](../../src/sound.ts)）。

| 音 | 使う場面 | 内容 |
|---|---|---|
| correct | 1問のスコアが4000点以上 | 三角波の上昇3音（G5→B5→E6） |
| miss | 1問のスコアが4000点未満 | 三角波の下降2音（G4→D4）、音量は控えめ |
| finish | 10問チャレンジ・全地点制覇の完了時 | 三角波の上昇4音（C5→E5→G5→C6） |

- **ライセンス**：このリポジトリの作者による自作。第三者の音源は含まない
- **再配布**：可（プロジェクト本体と同じ扱い）
- サウンドON/OFFは設定に保存され、OFF のときは一切音を鳴らさない

外部の音源ファイルを追加する場合は、CC0 など再配布可能なライセンスのものだけを使い、
この表に出典（配布元URL・ライセンス名）を追記すること。
